# Каталог продуктов

Приложение для просмотра и создания продуктов.

## Функциональность

- Каталог `/products`: загрузка продуктов из DummyJSON и кнопка «Показать больше».
- Добавление в избранное и фильтрация избранных продуктов.
- Удаление продуктов из локального каталога.
- Страница `/products/:id` с изображением, полным описанием, категорией, ценой и возвратом в каталог.
- Форма `/create-product` с обязательными полями и валидацией. Новый продукт сохраняется в общий store и появляется первым в каталоге.
- Созданные продукты сохраняются в `sessionStorage`: остаются после перезагрузки страницы до завершения сессии вкладки.

## Стек

- React, TypeScript, Vite.
- React Router — маршрутизация.
- Zustand — состояние и сохранение созданных продуктов.
- React Hook Form — форма и валидация.
- CSS Modules, Lucide React, ESLint.
